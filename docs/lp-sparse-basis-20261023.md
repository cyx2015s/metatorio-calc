# 浮点 LP 稀疏基分解（2026-10-23）

## 实现范围

`metatorio-lp` 的浮点 dual simplex 不再显式构造、更新 `m × m` 稠密基逆。
新增 `src/sparse_float_basis.rs`，以带行主元选择的稀疏 LU 和最多 128 个 eta
换基更新表示当前基。生产浮点路径没有稠密回退；小矩阵稠密消元仅作为测试 oracle。

- 行用 `BTreeMap` 保存非零系数，列关联集合定位消元目标，行置换保持原始约束身份。
- `solve` 求 `B⁻¹b`，`solve_transpose` 求 `B⁻ᵀc`。离基行通过转置求解单位向量获得。
- 每 128 次换基重分解，每 32 次换基重算原始和对偶向量；对偶漂移仍会尝试重分解。
- 重复系数累加，只移除精确为零的浮点结果，不以容差丢弃非零系数。
- 非基不等式 slack 的定价尺度按需求解 `B⁻¹eᵢ`，再计算其与基成本的绝对乘积之和，
  保持旧版尺度的数学语义，不保存完整逆矩阵。原始模型的精确/相对证书验证保持不变。
- 移除 4096 行硬限制，也移除 `cost_bounds` 沿用的 4096 行裁剪；后者仍每批最多添加 64 条边界。

资源保护限制保存的数值系数为 2,000,000、消元乘减工作量为 100,000,000，
eta 链最多 128 项。非有限数、奇异/过小主元、存储和工作量超限均作为数值搜索失败，
不能解释成模型不可行。分解构建和消元定期检查 observer；这仍是协作取消，
单次三角求解或单列装配没有即时中断保证。

## 验证方法

内核测试覆盖直接/转置求解的独立稠密 oracle、行置换、重复系数、结构列与 slack 混合基、
连续 eta 更新和重分解、生成矩阵，以及奇异/非有限/过小主元、存储、fill-in 和取消边界。
8192 阶对角基测试断言存储随非零数线性增长。

公开接口回归在 `tests/sparse_float.rs`：8192 条非空约束、160 次以上换基跨过重分解边界、
混合热启动基修复及零次换基重启、可行模型的奇异提示基拒绝。
所有成功搜索均重新构造并通过原始模型精确最优证书。
`cost_bounds` 另测超过旧行数限制时仍产生可验证提示。

可复现的小型规模实验：

```powershell
cargo test --release -p metatorio-lp --lib --tests
cargo test --release -p metatorio-solver --lib --tests
cargo run --release -p metatorio-lp --example sparse_float_smoke
```

历史回放使用本机已有 snapshot，旧版基线为 `e989f14c7a179509d9983b988ad1b00617e6a985`。
旧版二进制、相同输入的散列、限时回放脚本、运行输出放在
`local/lp-sparse-basis-20261023/`（本机忽略目录，不随仓库分发）。
回放逐例有 30 秒进程期限，最终结果另用 `lp_verify_witnesses` 验证。

### 定价尺度回归及修复

初版尝试用稀疏因子的逐层绝对值上界代替旧定价尺度。在 `history-0` 上，
该上界因忽略抵消而过宽，导致 dual drift，并在 30 秒回放期限内未完成。
这属于未完成搜索，不是不可行结论。恢复按需逆列求解的旧尺度后，
同一输入在 3.996 秒完成，1558 次浮点换基；旧版为 7.846 秒、1560 次换基。
目标值均为 `20187.391153513865`，独立验证确认精确最优，显示舍入后的约束和 gap 检查也通过。
该修复不放宽接受预算，也不恢复稠密逆。

最终 `cargo test --release -p metatorio-lp -p metatorio-solver --lib --tests`：
**156 通过、0 失败、6 忽略**（两个显式微基准、四个可选 HiGHS 审查测试）。
最终 examples 构建与 `git diff --check` 通过。

最终二进制回放结果（`final-replay/`）：

| 输入 | 列 / 行 | 旧版复跑秒数 | 新版最终秒数 | 独立证书复核 |
| --- | ---: | ---: | ---: | --- |
| history-0 | 99100 / 1001 | 6.598 | 9.066 | 精确最优，目标值与旧版相同 |
| ammonia-full | 3208 / 964 | 1.423 | 1.373 | 原始模型 Farkas 不可行证明 |

新版 history-0 的两次修复后回放为 3.996 与 9.066 秒，不能据此确认真实大模型稳定提速。
同输入单变量实验中，4096 行旧版浮点搜索 104.739 ms，新版最终 3.229 ms；
8192 行旧版被行数限制拒绝，新版最终 6.071 ms，均精确最优验证通过。
以上是本机少量观测，部分与编译或其他小验证并行；它们用于验证规模行为和定位回归，
不是稳定性能承诺，也没有测量进程峰值内存。

## 尚未覆盖的优化

本次只替换浮点候选搜索的基矩阵表示。精确重构的结构基有理数矩阵仍然稠密；
没有实现稀疏有理数 LU、Markowitz/列重排序、Forrest–Tomlin 更新或按 fill-in 自适应重分解。
稀疏输入仍可能产生大量 fill-in；数值系数上限不是整个进程的字节内存上限。
不据少量回放推断所有模组配方图的速度或数值鲁棒性。
