# 非负生产 LP 的相关子系统缩减（2026-10-20）

目的：在不放宽现有误差预算、不把搜索失败当作无解的前提下，减少浮点候选搜索中的无关变量。完整原模型的有理数检查、修复与证书仍然是最终判据。

## 适用条件与正确性

模型采用 `min cᵀx`，`x >= 0`，变量无有限上界，`c >= 0`；行规范为 `Ax <= b` 或等式。其他模型继续走原搜索路径。常数目标偏移不影响缩减。

从负右端不等式和非零右端等式开始，按系数符号求闭包：被选机制的消耗需要保留所有供应方向；等式还必须保留所有副产物处理方向。无需从外部原料寻找启动种子，生产循环可以保留。不能用普通的单向配方可达性代替这个闭包。

重复系数用精确二进制有理数求和后判断符号；没有小系数阈值。`1e20 + 1e-30 - 1e20` 的供应作用也不能丢弃。

另外，零成本、无任何净消耗、只影响不等式且全部净系数为负的无限供应列，可以替代相应行的其他供应方向。正消耗、等式作用、容量限制或正成本（即使只有 `1e-30`）都会阻止这项识别。这是矩阵条件，并不默认电力或热量免费。

正确性分为两面：

- 任意原可行解，删除未选变量并在必要时增加保留的纯免费供应，仍可行且成本不增加。
- 任意缩减可行解，给删除的变量补零，满足全部原约束。删除的不等式右端非负、保留列系数非正；删除的等式为零右端且保留列净系数为零。

对偶也可补零：保留的不等式只删除非负系数，或者存在纯免费供应迫使该行对偶价格为零；保留的等式不会删除非零净系数。于是缩减问题与原问题具有相同最优值，而非仅得到一个受限上界。

实现仍只使用缩减模型产生候选基，恢复原列、原行身份后在**完整原矩阵**上验证。缩减搜索或基重构失败不构成无解证明。

## 搜索策略

默认仅第一次浮点搜索使用缩减；后续原矩阵搜索、零传播与精确恢复保留。`METATORIO_LP_RELEVANCE=0` 可关闭，`=1` 可让每次浮点搜索均使用缩减，用于实验。同一进程环境设置必须在求解前完成。

成本上界实验 `METATORIO_LP_COST_BOUNDS` 仍默认关闭，与本次缩减独立。

## 复现入口

- `cargo test --release -p metatorio-lp --lib`
- `cargo test --release -p metatorio-solver --lib`
- `cargo test --release -p metatorio-shell --lib lengden_legendary_lds_auto_plan -- --ignored --nocapture`，设置唯一的 `LENGDEN_TEST_REPORT` 路径；可选 `METATORIO_LP_CAPTURE_DIR`。
