# 精确基矩阵全面稀疏化（2026-10-23）

后续精确 eta 更新与求解改进见 `lp-exact-updates-20261023.md`；本报告保留该轮实现和验证记录。

## 生产路径

结构基从原始行直接装配为 `Vec<BTreeMap<usize, Rational>>`，累加重复项并移除精确零。
新增 `sparse_exact_factor.rs`，以稀疏行、列关联集合、动态非零度数队列执行精确 LU：
优先选择非零项少的列和行，记录原始行列身份；不分配结构基方阵、完整逆或完整转置。
同一因子支持原始和转置求解，原始变量与对偶乘子仍使用原模型的二进制精确有理数。

`basis::System` 的稠密逆及四种逆更新公式已移除。原始优化、对偶修复、结构变量与 slack
交换都使用稀疏因子；当前精确换基会重建分解，替换成功前保留旧因子。
取消令牌传到装配、分解、求解和换基。旧 dense LU/Bareiss/分块实现仅在 `cfg(test)`
下编译，作为独立比较参考；独立小型 Gaussian/inverse oracle 也仅存在于测试。

移除 256 阶逆更新和 2048 阶重构门槛，以及原始/对偶循环中依据这些常量提前停止的分支。
浮点稀疏因子的固定存储/消元工作量门槛也移除；精确路径不新增固定维数、系数数目、工作量或
整数位数门槛。维度一致性、精确奇异检查、浮点非有限/过小主元检查仍保留。
浮点 128 次 eta 更新后的重分解是维护周期，不限制模型大小。
调用方指定的 deadline、取消和 pivot budget 继续生效。

## 验证范围

- 稀疏精确 LU 对独立稠密消元：分数、非对称、行列置换、直接与转置解。
- 8192 阶稀疏链因子存储不超过 `2n` 个有理数项，双向解均为预期全 1 向量。
- 公开接口重构 8192 个结构基本变量，通过非零目标下的精确最优证书。
- 4097 维基分别执行一次原始和对偶换基，覆盖缓存/非缓存入口，越过两个旧门槛。
- 混合基本 slack、非零下界/有限上界、重复项抵消、最小 subnormal 系数、精确奇异与取消。
- 四种换基形状及减到零维均对独立稠密 oracle；取消换基保留旧因子，随后可重试。

## 实际边界

“稀疏”指矩阵、因子和换基不再分配完整方阵/逆；解、右端项和定价向量仍使用线性长度数组。
填充可能使稀疏因子接近稠密，有理数位数也可能增长，实际规模受可用内存和计算时间约束。
单次大整数运算不能中途取消。当前没有精确 eta/Forrest–Tomlin 更新，频繁精确换基的性能
需独立衡量；没有因移除上限而宣称所有大模型都会快速完成。
