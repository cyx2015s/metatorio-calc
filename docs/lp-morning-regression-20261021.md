## 已定位的瓶颈与实验边界

1. **原版普通铁板**：首浮点候选约 1.66 秒、878 次换基，最初精确基重建仅约 0.12 秒；后续精确原始可行性修复占用约 45 秒，第二候选最终成功。把分数消元阈值从 32 提至 64 没有明显收益，已撤销。压缩浮点支持集得到的可行点缺少全模型对偶证明，未接入默认路径。
2. **原版精良铁板**：第一精确候选有一个约 `-1.415e-12` 的营养素路线用量。直接截为零会令某行纯相对误差达到 1，不能依据绝对数量小而忽略。种子列生成、精确支持集及强制零投影的有界实验均未完成有效证明，默认选种策略未改。
3. **重模组普通铁板**：原模型约 108 万列、7,427 行，相关子模型仍超过浮点稠密路径的 4,096 行限制。冷列生成消耗大量时间；现有约束生成通常排在它之后。直接试验约束生成，电力约束会拉入几乎所有列，因此活跃行少不代表列少。

### 当前前沿中的等价列

对 `x >= 0`、无有限上界、`c >= 0` 的模型，在**当前活跃行**上完全相同的列可合并，只保留成本最低者，同价选原始下标最小者。把其他列的非负用量相加至代表列，当前松弛问题的约束不变且成本不增；反向补零显然可行，因此松弛最优值不变。

新增约束可能区分这些列，下一轮重新分组；不会永久删除原始机制。分组只会拆分，原有代表仍可用，保留热启动基。重复系数项不经浮点合并，含重复项的列单独保留；有限界或带符号成本时不启用此合并。最终解和 Farkas 见证仍检查所有原始行列。

增加可选的 `METATORIO_PLAN_PROFILE=1`，分别记录枚举、可达性过滤、机制展开、供需诊断及 LP 建模；默认不输出这些阶段日志。诊断供需时原代码只读取生产者/消费者集合是否为空，现改为两个存在性标记，并避免每条关联重复克隆物品键；不改变任何 LP 流或缺失原料诊断。新增晚出现的生产者、外部供应、重复调用和禁止删除流的测试，当前求解器 **43/43** 通过。

模组钢板 `0114` 的实测说明诊断集合并非主要热点：候选枚举约 2.09 秒，可达性过滤约 **56.02 秒**，机制展开约 5.77 秒，供需诊断约 0.20 秒，LP 建模约 6.59 秒。过滤函数对同一配方的每种品质、插件和机器变体重新扫描全部建筑/解锁科技。

据此增加**一次规划快照内、按配方 ID 的解锁判断缓存**，并原地移除原本会被拒绝的候选。缓存不跨项目或可达性快照复用。功能测试比较未缓存判据，覆盖变体顺序、非配方机制及里程碑改变；runtime **84 通过、2 忽略**。
